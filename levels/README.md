## 武侠客栈 · 三杯

**一句话**：灯灭之前给三个客人斟酒——手稳，你就不像那个被通缉的人。

| 项 | 定下来的 |
| --- | --- |
| 你是谁 | 陨落宗门的嫡子，正被通缉，逃进这家客栈 |
| 三杯是谁 | ① 刀客（验身份）② 捕快（验画像）③ 故人（认得你） |
| 核心机制 | 按住蓄力 → 松手停手 → 液面稳下来自动判定 |
| 第三杯 | 倒过三成，壶被拿走，他替你倒满；这一杯不判 |
| 失手代价 | 不扣血、不判死，只把「手抖」带进后面几杯 |
| 带走的 | 他的刀 |
| 时长 | 约 90–120 秒（三杯 + 六段剧情） |
| 失败 | 没有失败，洒光了也能过，只是结尾台词不同 |

### 文件

- `wuxia-inn/index.html`：整关就这一个文件，**单文件、零依赖、无外链、无 alert/confirm**，`file://` 双击即可运行。

### 操作

- 点击：翻剧情
- 按住鼠标 / 空格：提壶斟酒
- 松开：停手，等液面稳住后自动判定
- `R`：重开

### 手感参数

都在 `index.html` 开头的 `TUNE`（第 60 行附近）：

| 参数 | 值 | 管什么 |
| --- | --- | --- |
| `chargePow` | 1.55 | 蓄力加速曲线，调大后半段更猛 |
| `inertia` / `decay` | 0.22 / 0.80 | 松手后还冲多远 |
| `tolBase` | 0.11 | 第一杯的容差 |
| `tolStep` | 0.012 | 每杯收窄多少 |
| `targetMin/Max` | 0.36 / 0.86 | 刻线随机区间 |
| `STORY_HOLD` | 7.4 | 剧情页自动翻页的秒数（点击可提前翻） |

第三杯接手的节奏在 update 循环 `phase==='takeover'` 一段（第 282 行起）：`0.14s` 出台词、`0.62s` 倾壶、`0.95s` 起以 `0.35/秒` 上涨。
