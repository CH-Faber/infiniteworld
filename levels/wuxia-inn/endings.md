# 武侠客栈 · 六种收尾

接在「他解下自己的刀，搁在桌上」之后。每段空行 = 游戏里的一页，一页不超过两行；点击翻页，不点则 7.4 秒自动过（`STORY_HOLD`）。

---

## 版本一 · 留白（不真打，门开即止）

```
门开了。雪在地上积了半尺。
灯下站着三个人。

「跑堂的。」
「把刀放下。」

你握紧了刀。
雪落在刀背上，没化。
```

**效果**：最省成本，也最狠。刀举起来就停住，剩下的交给玩家自己想。

---

## 版本二 · 三刀带伤（打戏，第一刀就中）

```
门外的雪，比三个月前那场火还白。
捕快站在灯下，身后四个人。

「跑堂的。」
「把刀放下。」

第一刀从左边来。
你没看清，只听见风。

刀进了你的肩。
热的。

第二刀、第三刀——
你都接住了。

最后站着的人是你。
雪落在刀上，化得很慢。
```

**效果**：三刀对应三杯，第一刀必须中——手抖的债，用血还。

---

## 版本三 · 旧人断后（情义最重）

```
门外站着捕快和四个衙役。
旧宗门人先你一步出去了。

「师父的刀，不是让你死在门口的。」

他替你挡了第一刀。
血落在雪上，很快就看不见了。

你把刀抽出来的时候，
手不抖了。

剩下三刀，你替他接完。

巷口很静。
你身上只有一道口子。

他的刀，和他的人，都留在雪里。
```

**效果**：把他的转折（递令又烧令）收到极致，但代价是死人，会抢走你的主角时刻。

---

## 版本四 · 反杀（爽，刀不沾血）

```
门外四个人，灯下只见两把刀。

「跑堂的，把刀放下。」

你没放。
你先出的刀。

雪地上多了四道痕。
你的刀上只有一道。

捕快没动。
他把告示收进袖子，让开了路。

「不像。」
「走吧。」

你走出去，没回头。
巷子尽头还亮着一盏灯。
```

**效果**：最好玩，最轻。适合你想要「出口气」的版本。

---

## 版本五 · 惨胜（跪着也能活）

```
门外的雪，埋到脚踝。
捕快身后站着五个人。

第一刀你躲开了。
第二刀没有。

第三刀你跪下去了。
但刀还在手里。

你用刀撑着站起来。
他们没再动。

血滴在雪上，一个一个洞。

巷口的灯灭了。
你还站着。
```

**效果**：把「活着」写成「差点没活着」，最重，也最像武侠。

---

## 版本六 · 不打，只走（余味最长）

```
他走了。
你把刀别在腰上。

门推开，雪灌进来。
外面没有人。

你走进雪里。
没有再回头。

通缉令贴到第八个县城的时候，
你已经不低头了。
```

**效果**：不打反而收得最远——开场「你学会了低头」，结尾「你已经不低头了」，一句话走完整个成长。

---

## 选用建议

排序：**版本六 ≥ 版本二 > 版本五 > 版本一 > 版本四 > 版本三**

版本六几乎零成本，但主题闭合最完整；版本二是唯一让「打戏」变成玩法而不是过场的写法。

两个都可以留，做成**完美通关走六、失手走二**，代价和奖励也就分开了。
