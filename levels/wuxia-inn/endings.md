# 武侠客栈 · 六种收尾

接在「他解下自己的刀，搁在桌上」之后。每段空行 = 游戏里的一页，一页不超过两行；点击翻页。

**说话的是谁**：从熔岩城穿越过来、落在阿七身体里的人。阿七是陨落宗门的嫡子，被通缉；刀是阿七师父的刀；通缉令上画的是阿七的脸。你不是他，你只是借了他的脸、他的手、他的债。

---

## 版本一 · 留白（不真打，门开即止）

```
门开了。雪在地上积了半尺。
灯下站着三个人。

「阿七。」
「把刀放下。」

你握紧了刀。
手是阿七的，抖是你的。

雪落在刀背上，没化。
```

**效果**：最省成本，也最狠。刀举起来就停住，剩下的交给玩家自己想。

---

## 版本二 · 三刀带伤（打戏，第一刀就中）

```
门外的雪，比山门那场火还白。
捕快站在灯下，身后四个人。

「阿七。」
「把刀放下。」

第一刀从左边来。
你没看清，只听见风。

刀进了你的肩。
热的——这具身体的血，也烫。

第二刀、第三刀——
你都接住了。

最后站着的人是你。
雪落在刀上，化得很慢。
```

**效果**：三刀对应三杯，第一刀必须中——手抖的债，用血还。

---

## 版本三 · 旧人断后（情义最重）

```
门外站着捕快和四个衙役。
旧宗门人先你一步出去了。

「师父的刀，不是让阿七死在门口的。」

他替你挡了第一刀。
血落在雪上，很快就看不见了。

你把刀抽出来的时候，
手不抖了。

剩下三刀，你替他接完。

巷口很静。
你身上只有一道口子。

他到死都以为，护住的是阿七。
```

**效果**：把他的转折（递令又烧令）收到极致。最重的一刀是他自己认错了人——他认的是阿七，不是里面这个人。

---

## 版本四 · 反杀（爽，刀不沾血）

```
门外四个人，灯下只见两把刀。

「阿七，把刀放下。」

你没放。
你先出的刀。

雪地上多了四道痕。
阿七的刀，你的手。

捕快没动。
他把告示收进袖子，让开了路。

「不像。」
「走吧。」

你走出去，没回头。
巷子尽头还亮着一盏灯。
```

**效果**：最好玩，最轻。他那句「不像」，是这一关唯一一次差点看穿——但他还是看错了方向。

---

## 版本五 · 惨胜（跪着也能活）

```
门外的雪，埋到脚踝。
捕快身后站着五个人。

第一刀你躲开了。
第二刀没有。

第三刀你跪下去了。
膝盖是阿七的，疼是你的。

你用刀撑着站起来。
他们没再动。

血滴在雪上，一个一个洞。

巷口的灯灭了。
你还站着。

这张脸，从今夜起才算是你的。
```

**效果**：把「活着」写成「差点没活着」。最后一页是身份的落地——血是替这具身体流的，脸才归你。

---

## 版本六 · 不打，只走（余味最长）

```
他走了。
刀留下了。

门推开，雪灌进来。
外面没有人。

你走进雪里。
这张脸不是你的，路是你的。

通缉令贴到第八个县城的时候，
你终于不再替这张脸低头。
```

**效果**：不打反而收得最远。开场「你学会了低头」，结尾「你不再替这张脸低头」——成长落在这张借来的脸上。

---

## 怎么选

| 洒了几杯 | 走哪一版 |
| --- | --- |
| 0 | 版本六（不打，只走） |
| 1 | 版本五（惨胜） |
| 2 | 版本二（三刀带伤） |

另外三版（一、三、四）留作备选，暂不进游戏。
